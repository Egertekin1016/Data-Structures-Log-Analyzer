# Data-Structures-Log-Analyzer
Milyonlarca ağ logunu işleyerek siber tehditleri analiz eden istihbarat sistemi. Java ile geliştirilmiş olup; tehdit önceliklendirmesi (Max-Heap), ağ sızma tespiti (Graph/BFS) ve hızlı arama (BST/Hash Map) için 11 farklı veri yapısı ile O(1) ve O(logN) seviyesinde optimize edilmiştir.
